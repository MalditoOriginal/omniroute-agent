Multiagent Router PRO
Оркестратор мультиагентной системы на базе OmniRoute и Aider.Система автоматически маршрутизирует запросы к нужной модели (терминал, кодинг, медиа, финансы) в зависимости от интента пользователя.

Быстрый старт (Windows 11)
Убедитесь, что установлен Python 3.10+ и Node.js.
Откройте PowerShell в папке проекта.
Запустите автонастройку:powershell -ExecutionPolicy Bypass -File setup.ps1
Следуйте инструкциям скрипта (создайте Combo в дашборде OmniRoute, вставьте API ключ).
Перезапустите терминал.
Запустите ядро:python multiagent_router_pro.py
Команды
найди ошибку в логах -> направится в TerminalAgent
исправь скрипт main.py -> направится в CodingAgent (Aider)
проанализируй screenshot.png -> направится в MediaAgent (Vision)
/prod перепиши архитектуру -> принудительный вызов тяжелого прод-кодера
🚀 Как это теперь запустить (Пошагово для Win 11)
Создайте папку D:\OmniRoute-Agent.
Создайте в ней 5 файлов, описанных выше, и скопируйте туда код.
Откройте PowerShell от имени администратора.
Перейдите в папку: cd D:\OmniRoute-Agent
Запустите настройку: powershell -ExecutionPolicy Bypass -File setup.ps1
(Скрипт поставит OmniRoute, попросит ключ и настроит всё автоматически).
Когда скрипт отработает, закройте PowerShell и откройте его заново (чтобы применились переменные OPENAI_API_KEY).
Запустите систему: python multiagent_router_pro.py
